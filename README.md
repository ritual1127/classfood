# classfood — 구전공 급식 및 시간표

**👉 https://ritual1127.github.io/classfood/**

구미전자공업고등학교의 **급식과 시간표를 한 화면에서** 보는 웹앱입니다.
교육부 나이스(NEIS) 공식 API에 실시간으로 연결돼 있어 따로 업데이트할 필요가 없습니다.

앱 설치도, 로그인도 없습니다. 링크만 열면 됩니다.
휴대폰에서 **홈 화면에 추가** 해두면 앱처럼 쓸 수 있습니다.

---

## 기능

| | |
|---|---|
| 🍽️ **급식** | 조식 · 중식 · 석식을 메뉴 번호와 함께 표시 (알레르기 유발 번호는 자동으로 지워서 보여줍니다) |
| 📅 **시간표** | 선택한 학년 · 반 · 학과의 교시별 과목 |
| 👥 **학년/반/학과 선택** | 1~3학년 · 1~8반 · 전자과 / 메카트로닉스과 |
| 🗓️ **날짜 이동** | 좌우 화살표, 주간 달력(월~금) 직접 선택, **좌우 스와이프** |
| 🌙 **다크 모드** | 우측 상단 버튼 |
| 📤 **복사 · 공유** | 급식을 텍스트로 복사하거나 카톡 등으로 바로 공유 |

**선택한 학년 · 반 · 학과와 다크 모드 설정은 기기에 저장됩니다.** 다음에 열면 그대로 복원됩니다.

---

## 쓰는 법

1. 링크를 엽니다.
2. 상단에서 **학년 · 반 · 학과** 를 자기 것으로 맞춥니다. (한 번만 하면 계속 기억합니다)
3. 급식과 시간표가 바로 나옵니다.
4. 다른 날을 보려면 화살표를 누르거나 화면을 **좌우로 밀면** 됩니다.
5. 급식을 친구에게 보낼 땐 아래 **공유하기** 를 누르세요.

> 주말과 방학에는 "급식 정보가 없어요" 라고 나옵니다. 오류가 아니라 나이스에 데이터가 없는 것입니다.
> 시간표와 급식은 학교에서 나이스에 입력해야 올라오므로, 아주 최근 날짜는 아직 비어 있을 수 있습니다.

## 데이터 출처

교육부 **나이스 교육정보 개방 포털** 공식 API를 그대로 씁니다.

| 항목 | 값 |
|---|---|
| 급식 | `mealServiceDietInfo` |
| 시간표 | `hisTimetable` |
| 교육청 코드 | `R10` (경상북도교육청) |
| 학교 코드 | `1421116` (구미전자공업고등학교) |

중간 서버가 없어서 브라우저가 나이스에 직접 요청합니다.
**개인정보를 수집하지 않고, 설정값은 기기 안(localStorage)에만 저장됩니다.**

## 다른 학교로 바꾸기

`index.html` 위쪽의 상수 세 줄만 고치면 다른 학교에서도 그대로 동작합니다.

```js
const KEY   = '발급받은_인증키';
const OFFICE= 'R10';        // 교육청 코드
const SCHOOL= '1421116';    // 학교 코드
```

### 1. 인증키 발급

https://open.neis.go.kr 에서 회원가입 후 인증키를 발급받으세요. 무료입니다.

> 저장소에 들어 있는 키는 이 프로젝트용이며 **일일 호출 한도를 함께 쓰게 됩니다.**
> 포크해서 쓸 거라면 **본인 키를 발급받아 교체하는 걸 권합니다.**

### 2. 학교 코드 찾기

발급받은 키로 아래 주소를 브라우저에 넣으면 코드가 나옵니다. (`학교이름` 부분만 바꾸세요)

```
https://open.neis.go.kr/hub/schoolInfo?KEY=본인키&Type=json&SCHUL_NM=학교이름
```

응답에서 `ATPT_OFCDC_SC_CODE` 가 교육청 코드, `SD_SCHUL_CODE` 가 학교 코드입니다.

**교육청 코드 참고**
`B10` 서울 · `C10` 부산 · `D10` 대구 · `E10` 인천 · `F10` 광주 · `G10` 대전 · `H10` 울산 · `I10` 세종
`J10` 경기 · `K10` 강원 · `M10` 충북 · `N10` 충남 · `P10` 전북 · `Q10` 전남 · `R10` 경북 · `S10` 경남 · `T10` 제주

### 3. 배포

1. 이 저장소를 **Fork**
2. `Settings` → `Pages` → Source 를 `main` / `/ (root)` 로 지정
3. 1~2분 뒤 `https://<본인아이디>.github.io/classfood/` 에서 열립니다

> 일반계 고등학교라면 학과 선택은 필요 없습니다. 상단 `deptSelect` 부분과
> `loadTimetable()` 안의 학과 필터를 지우면 더 단순해집니다.

## 학과 필터링에 대해

구전공은 **같은 학년·반이라도 학과별로 수업이 갈립니다.** 그런데 나이스는
한 반의 시간표를 요청하면 **두 학과 과목을 모두** 돌려줍니다. (예: 2학년 2반 2교시에
메카트로닉스과 "센서 활용 기술"과 전자과 "하드웨어 부품 선정"이 동시에 옵니다)

그래서 `loadTimetable()` 이 한 교시에 여러 과목이 오면 선택한 학과 것만 남기고 걸러냅니다.

> ⚠️ **알려진 문제**
> 현재 이 필터는 **과목 이름을 하드코딩한 목록**으로 걸러냅니다.
> 그래서 학기가 바뀌어 과목명이 달라지면 **엉뚱한 학과 시간표가 보일 수 있습니다.**
>
> 나이스 응답에는 학과명이 담긴 **`DDDEP_NM`** 필드가 이미 들어 있어서
> (`DDDEP_NM === currentDept` 비교) 이걸 쓰면 과목명과 무관하게 항상 정확합니다.
> 개선 여지가 있는 부분입니다.

## 고치기

`index.html` 한 파일이 전부입니다.

| 대상 | 위치 |
|---|---|
| 인증키 · 학교 코드 | 파일 상단 `KEY`, `OFFICE`, `SCHOOL` |
| 기본 학년/반/학과 | `currentGrade`, `currentClass`, `currentDept` |
| 반 개수 · 학과 목록 | `<select id="classSelect">`, `<select id="deptSelect">` |
| 급식 불러오기 | `loadMeals()` |
| 시간표 불러오기 · 학과 필터 | `loadTimetable()` |
| 공유 문구 | `getMealText()` |
| 색상 · 테마 | `<style>` 상단 |

## 기술 메모

- 순수 HTML/CSS/JS 단일 파일, 프레임워크·빌드 없음
- 급식과 시간표를 각각 메모리에 캐시해 같은 날짜 재조회 시 요청하지 않음
- 알레르기 번호는 `(5.6.10)` 형태를 정규식으로 제거
- 공유는 `navigator.share` 지원 시 네이티브 공유, 아니면 클립보드 복사로 대체
- 모바일 우선, 날짜 전환에 슬라이드 애니메이션
